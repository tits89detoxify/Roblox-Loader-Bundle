## FAQ

### What is XCutors?

XCutors is a Windows desktop application that bundles several popular Roblox executors (Volt, Synapse Z, Potassium, Wave) along with a universal loader for easy management.

### Is XCutors free to use?

XCutors itself is free and open-source. Some individual executors included in the package may have their own licensing terms.

### Which Windows versions are supported?

XCutors supports Windows 10 and Windows 11 (64-bit). Older versions of Windows are not officially supported.

### How do I switch between executors?

Open the xcutorsLoader dashboard, select the executor you want from the list, and click Attach. You can switch at any time without restarting the loader.

### Do I need to disable my anticomponent?

Some anticomponent software may flag executor files due to their injection functionality. You may need to add an exception for the XCutors folder.

### How often is XCutors updated?

The XCutors package is updated regularly to maintain compatibility with Roblox client updates. Check the Releases page for the latest version.

### Can I add my own scripts to the script hub?

Yes. Place your Lua script files in the scripts/ folder inside the XCutors directory, and they will appear in the built-in script hub.

### What should I do if an executor fails to attach?

Ensure Roblox is running, try restarting both Roblox and XCutors, check for updates, and review the log file in the logs/ folder for error details.
